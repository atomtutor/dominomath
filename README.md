# 🧩 도미노 연산 퍼즐 생성기

수의 범위와 연산식 종류를 고르면 **시작 → 끝으로 이어지는 12조각 도미노 연산 체인**을 자동으로 만들어주는 웹 도구입니다. 결과를 화면에서 바로 확인하고, **A4 3쪽짜리 PDF**(① 문제지 ② 붙임판 ③ 정답)로 내려받아 인쇄·배포할 수 있습니다.

순수 HTML/CSS/JS로만 만들어졌고 **모든 라이브러리와 폰트를 저장소 안에 내장**했기 때문에, GitHub Pages 등 어떤 정적 호스팅에 올려도 별도 서버나 외부 CDN 연결 없이 그대로 동작합니다. (학교망처럼 외부 CDN이 막힌 환경에서도 PDF 다운로드가 정상 동작하도록 하기 위함입니다.)

## 데모

`index.html`을 더블클릭해서 브라우저로 열거나, GitHub Pages로 배포한 주소로 접속하면 바로 사용할 수 있습니다.

## 사용법

1. **수의 범위**: 최소~최대 숫자를 입력합니다. 문제와 정답에 나오는 모든 숫자가 이 범위 안에서 만들어집니다.
2. **연산식 종류**를 고릅니다.

   | 옵션 | 구성 |
   |---|---|
   | 덧셈 | 덧셈식만 출제 |
   | 뺄셈 | 뺄셈식만 출제 |
   | 덧셈+뺄셈 | 덧셈식과 뺄셈식이 섞여서 출제 |
   | 곱셈 (+덧셈) | 곱셈식(2~9단)과 덧셈식이 섞여서 출제 |
   | 혼합 | 덧셈·뺄셈·곱셈 세 종류가 모두 출제 |
   | 10 만들기 | 범위가 자동으로 0~10으로 고정되며, `2+8`처럼 10을 만드는 덧셈과 `10-9`처럼 10에서 빼는 뺄셈만 출제 |

3. **🎲 퍼즐 생성** 버튼을 누르면 A4 실제 크기(210×297mm) 미리보기 3쪽(문제지·붙임판·정답)이 나타납니다. 마음에 들 때까지 여러 번 눌러 다시 만들 수 있습니다.
4. **⬇ PDF로 다운로드** 버튼을 누르면 3쪽을 하나의 PDF 파일로 저장합니다.
   - **1쪽 문제지**: 학생이 오려서 사용할 12조각이 무작위 순서로 배치됩니다.
   - **2쪽 붙임판**: 오려낸 조각을 시작~끝 순서로 붙일 수 있도록 정답과 같은 모양의 빈 칸이 인쇄됩니다.
   - **3쪽 정답**: 붙임판과 동일한 모양에 정답이 그대로 채워져 있어 교사가 바로 채점할 수 있습니다.
5. PDF를 인쇄한 뒤, 학생들이 1쪽을 점선을 따라 오려서 2쪽 붙임판에 시작부터 끝까지 순서대로 이어 붙이면 완성입니다. 3쪽 정답으로 바로 확인할 수 있습니다.

## 퍼즐이 만들어지는 방식

- 12개의 조각이 `시작 → 문제1 → 문제2 → … → 문제11 → 끝` 순서의 체인을 이룹니다.
- 앞 조각 오른쪽 문제의 **정답**이 다음 조각 왼쪽 값과 일치해야 이어지도록 만들어집니다.
- 이어지는 방식은 두 가지가 섞여 있습니다.
  - **단순 계산 결과**: 예) `7×3` → `21`
  - **교환법칙**: 예) `3+5` → `5+3` (덧셈·곱셈에서만 사용, 뺄셈은 결괏값으로만 연결)
- 1쪽(문제지)에서는 완성된 체인의 순서가 무작위로 섞이고, 각 조각의 좌우도 50% 확률로 뒤바뀐 채 배치되어 매번 다른 문제지가 만들어집니다.
- 2쪽(붙임판)과 3쪽(정답)은 **같은 모양의 고정된 뱀 모양 틀**에 12조각을 순서대로 배치합니다. 어떤 연산 모드를 고르든 이 틀의 모양은 항상 같아서, 붙임판에 오려 붙인 결과가 정답과 정확히 같은 자리에 놓이는지 바로 비교할 수 있습니다.

## 폴더 구조

```
.
├── index.html                     # 생성기 본체 (UI + 로직 + PDF 내보내기)
├── vendor/
│   ├── html2canvas.min.js         # 화면을 이미지로 캡처 (MIT License)
│   └── jspdf.umd.min.js           # PDF 파일 생성 (MIT License)
├── fonts/
│   ├── NotoSansKR-Regular.woff2   # 한글 표시용 서브셋 폰트
│   └── NotoSansKR-Bold.woff2
└── README.md
```

## GitHub Pages로 배포하기

1. 이 폴더 전체를 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 배포할 브랜치(예: `main`)와 폴더(`/root`)를 지정합니다.
3. 잠시 후 발급되는 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 바로 사용할 수 있습니다.

별도의 빌드 과정이나 `npm install`이 필요 없습니다. 정적 파일 그대로 올리면 됩니다.

## 로컬에서 확인하기

인터넷 연결 없이도 완전히 동작합니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
git clone <이 저장소 주소>
cd <저장소 폴더>
open index.html   # macOS
# 또는 그냥 파일 탐색기에서 더블클릭
```

## 기술 노트

- **PDF 생성**: `html2canvas`로 문제지 DOM을 고해상도(3배) 캔버스로 캡처한 뒤, `jsPDF`로 A4(210×297mm) 한 페이지에 그대로 삽입합니다.
- **한글 폰트**: Noto Sans KR을 이 앱에서 실제로 쓰는 글자만 골라 서브셋으로 만들어 `woff2`로 내장했습니다(폰트 파일 용량을 최소화). 외부 폰트 서비스에 연결하지 않습니다.
- **오프라인 동작 확인**: Playwright + 크로미움으로 네트워크를 완전히 차단한 상태에서 6가지 연산 모드 전체에 대해 반복 테스트하여 PDF 다운로드가 정상 동작함을 확인했습니다.
