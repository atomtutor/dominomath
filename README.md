# 🧩 도미노 연산 퍼즐 - 화면 활동

수의 범위와 연산식 종류를 고르면 **시작 → 끝으로 이어지는 12조각 도미노 연산 체인**을 자동으로 만들어주는 웹 도구입니다. 두 가지 방식으로 바로 사용할 수 있습니다.

- **🖱 화면 활동** (기본 탭): 학생이 화면에서 카드를 드래그해서 붙임판에 순서대로 놓으며 즉석에서 퍼즐을 완성합니다. 초급/중급 난이도를 고를 수 있고, 12조각을 모두 맞추면 색종이 효과와 팡파레 효과음이 나오는 완성 화면이 뜹니다.
- **🖨 인쇄용 문제지**: 기존 방식대로 **A4 3쪽짜리 PDF**(① 문제지 ② 붙임판 ③ 정답)를 내려받아 인쇄·배포할 수 있습니다.

순수 HTML/CSS/JS로만 만들어졌고 **모든 라이브러리와 폰트를 저장소 안에 내장**했기 때문에, GitHub Pages 등 어떤 정적 호스팅에 올려도 별도 서버나 외부 CDN 연결 없이 그대로 동작합니다. (학교망처럼 외부 CDN이 막힌 환경에서도 정상 동작하도록 하기 위함입니다.)

## 데모

`index.html`을 더블클릭해서 브라우저로 열거나, GitHub Pages로 배포한 주소로 접속하면 바로 사용할 수 있습니다.

## 공통 사용법 (퍼즐 만들기)

1. **수의 범위**: 최소~최대 숫자를 입력합니다. 문제와 정답에 나오는 모든 숫자가 이 범위 안에서 만들어집니다.
2. **연산식 종류**를 고릅니다.

   | 옵션 | 구성 |
   |---|---|
   | 덧셈 | 덧셈식만 출제 |
   | 뺄셈 | 뺄셈식만 출제 |
   | 덧셈+뺄셈 | 덧셈식과 뺄셈식이 섞여서 출제 |
   | 곱셈 | 곱셈식(2~9단)만 출제 (단, 연결 부분에 `4×4→4+4+4+4` 같은 반복 덧셈이 등장할 수 있음) |
   | 혼합 | 덧셈·뺄셈·곱셈 세 종류가 모두 출제 |
   | 10 만들기 | 범위가 자동으로 0~10으로 고정되며, `2+8`처럼 10을 만드는 덧셈과 `10-9`처럼 10에서 빼는 뺄셈만 출제 |

3. **난이도**를 고릅니다.

   | 옵션 | 구성 |
   |---|---|
   | 초급 | 각 붙임판 칸마다 원래 설계된 정답 카드만 들어갑니다. |
   | 중급 | 활성 칸이 지금 필요로 하는 **값**만 맞으면 어떤 카드든 넣을 수 있습니다. 값이 같은 카드가 여러 장일 때는 그중 어떤 것을 골라도 되지만, 잘못 고르면(예: `끝` 카드를 너무 일찍 써버리는 경우) 더 이상 이어지는 카드가 없어 막힐 수 있습니다 — 이때는 붙임판의 **↺ 다시 시작**으로 되돌립니다. |

4. **🎲 퍼즐 생성** 버튼을 누르면 새 12조각 체인이 만들어지고, 두 탭(화면 활동 / 인쇄용 문제지)에 동시에 반영됩니다. 마음에 들 때까지 여러 번 눌러 다시 만들 수 있습니다.

## 🖱 화면 활동 탭 사용법

1. **🎲 퍼즐 생성**을 누르면 왼쪽에 12장의 카드 더미(덱), 오른쪽에 뱀 모양의 빈 붙임판이 나타납니다. 화면(모니터) 크기에 맞춰 카드와 붙임판이 자동으로 최대한 크게 표시되고, 스크롤 없이 한 화면에 들어오도록 조정됩니다.
2. 붙임판에는 항상 **시작 칸부터 순서대로 하나씩만** 반짝이는 테두리로 활성화됩니다(활성 슬롯).
3. 덱에서 알맞은 카드를 찾아 활성 슬롯 위로 **드래그해서 놓으면**(카드가 칸보다 커도 칸을 덮기만 하면 인식됩니다) 정답인 경우 그 자리에 딱 맞춰 끼워지고, 다음 슬롯이 자동으로 활성화됩니다.
4. 카드가 틀렸거나 활성 슬롯이 아닌 곳에 놓으면 카드가 흔들린 뒤 덱으로 돌아갑니다. 실패해도 감점 없이 다시 시도할 수 있습니다.
5. **방금 붙인 카드를 잘못 넣었다면**, 그 칸에 표시된 빨간 **✕** 를 클릭하세요 — 카드가 다시 덱으로 돌아가고 그 칸이 다시 활성화됩니다. 연속으로 클릭하면 한 단계씩 계속 되돌릴 수 있습니다(가장 최근에 붙인 칸만 되돌릴 수 있어요).
6. 완전히 막혀서 처음부터 다시 풀고 싶다면 붙임판의 **↺ 다시 시작** 버튼을 누르세요. 같은 문제, 같은 카드 배치로 붙임판만 비워집니다.
7. 12조각을 모두 순서대로 이으면 색종이(컨페티) 애니메이션과 팡파레 효과음(Web Audio로 그 자리에서 합성 — 외부 음원 파일 없음)이 나오는 완성 화면이 뜹니다.
8. 완성 화면에서 **🔄 다시 도전** 버튼을 누르면 같은 문제·같은 카드 배치로 붙임판이 초기화되어 다시 연습할 수 있습니다. 새 문제를 원하면 **🎲 퍼즐 생성**을 다시 누르면 됩니다.

터치스크린(태블릿)에서도 포인터 이벤트 기반으로 동일하게 드래그·클릭할 수 있습니다.

## 🖨 인쇄용 문제지 탭 사용법

1. **🎲 퍼즐 생성** 버튼을 누르면 A4 실제 크기(210×297mm) 미리보기 3쪽(문제지·붙임판·정답)이 나타납니다.
2. **⬇ PDF로 다운로드** 버튼을 누르면 3쪽을 하나의 PDF 파일로 저장합니다.
   - **1쪽 문제지**: 학생이 오려서 사용할 12조각이 무작위 순서로 배치됩니다.
   - **2쪽 붙임판**: 오려낸 조각을 시작~끝 순서로 붙일 수 있도록 정답과 같은 모양의 빈 칸이 인쇄됩니다.
   - **3쪽 정답**: 붙임판과 동일한 모양에 정답이 그대로 채워져 있어 교사가 바로 채점할 수 있습니다.
3. PDF를 인쇄한 뒤, 학생들이 1쪽을 점선을 따라 오려서 2쪽 붙임판에 시작부터 끝까지 순서대로 이어 붙이면 완성입니다. 3쪽 정답으로 바로 확인할 수 있습니다.

화면 활동과 인쇄용 문제지는 **같은 체인 데이터**를 공유합니다 — 즉, 한 번 퍼즐 생성을 누르면 두 탭 모두 같은 문제로 채워집니다.

## 퍼즐이 만들어지는 방식

- 12개의 조각이 `시작 → 문제1 → 문제2 → … → 문제11 → 끝` 순서의 체인을 이룹니다.
- 앞 조각 오른쪽 문제의 **정답**이 다음 조각 왼쪽 값과 일치해야 이어지도록 만들어집니다.
- 이어지는 방식은 다음이 섞여 있습니다(교환법칙 비중은 낮게, 나머지는 고르게 배분).
  - **단순 계산 결과**: 예) `7×3` → `21`
  - **교환법칙**: 예) `3+5` → `5+3` (덧셈·곱셈에서만 사용, 뺄셈은 결괏값으로만 연결)
  - **응용 수식(곱셈 전용)**: 예) `4×5` → `4+4+4+4+4` 같은 반복 덧셈 형태로도 연결됩니다.
- 카드 순서는 매번 무작위로 섞입니다. 인쇄용 문제지(1쪽)는 각 카드의 좌우도 50% 확률로 뒤바뀐 채 배치되지만, 화면 활동 덱은 각 카드가 원래 들어갈 붙임판 칸이 요구하는 좌우 순서 그대로 표시됩니다 — 그래야 카드를 붙일 때 좌우가 뒤집히지 않고, 붙임판의 맞닿은 면이 항상 같은 값을 보여줍니다. 단, **`끝` 조각만은 예외**로 좌우가 절대 뒤바뀌지 않습니다 — 숫자·연산 기호와 달리 `끝`이라는 글자는 뒤집히면 알아보기 어렵고, 어차피 맨 마지막에 고정된 위치(붙임판 왼쪽 아래)에 붙이는 조각이라 뒤집지 않고 그대로 붙일 수 있게 항상 같은 방향으로 인쇄됩니다.
- 붙임판(화면 활동의 슬롯, 인쇄용 2·3쪽)은 **같은 모양의 고정된 뱀 모양 틀**에 12조각을 순서대로 배치합니다. 어떤 연산 모드를 고르든 이 틀의 모양은 항상 같습니다.

## 폴더 구조

```
.
├── index.html                     # 앱 본체 (UI + 퍼즐 생성 로직 + 화면 활동 드래그앤드롭 + PDF 내보내기)
├── vendor/
│   ├── html2canvas.min.js         # 화면을 이미지로 캡처 (MIT License, 인쇄용 탭에서만 사용)
│   └── jspdf.umd.min.js           # PDF 파일 생성 (MIT License, 인쇄용 탭에서만 사용)
├── fonts/
│   ├── NotoSansKR-Regular.woff2   # 한글 표시용 서브셋 폰트
│   └── NotoSansKR-Bold.woff2
└── README.md
```

## GitHub Pages로 배포하기

1. 이 폴더 전체를 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 배포할 브랜치(예: `main`)와 폴더(`/root`)를 지정합니다.
3. 잠시 후 발급되는 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 바로 사용할 수 있습니다.

별도의 빌드 과정이나 `npm install`이 필요 없습니다. 정적 파일 그대로 올리면 됩니다.

## 로컬에서 확인하기

인터넷 연결 없이도 완전히 동작합니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
git clone <이 저장소 주소>
cd <저장소 폴더>
open index.html   # macOS
# 또는 그냥 파일 탐색기에서 더블클릭
```

## 기술 노트

- **화면 활동 드래그앤드롭**: Pointer Events(`pointerdown`/`pointermove`/`pointerup`/`pointercancel`)로 구현되어 마우스와 터치스크린 모두 동일하게 동작합니다. 놓았을 때 판정은 활성 슬롯의 중심점이 카드의 현재 영역 안에 들어오는지로 검사합니다(카드가 칸보다 커도 정확한 픽셀을 맞출 필요 없이 칸을 덮기만 하면 인식). 초급은 좌우 순서 상관없이 그 칸의 원래 정답 값과 일치하는지, 중급은 카드의 "들어오는 값"이 현재 필요한 값과 일치하는지로 판정합니다.
- **카드·붙임판 크기 비율**: 문제카드(덱)는 항상 2열×6행으로 배치되고, 붙임판은 6×9칸 크기의 뱀 모양 틀입니다. 두 영역 모두 같은 기준 한 칸 크기(`unit`)에서 크기를 계산하기 때문에, 카드의 반쪽 칸과 붙임판의 한 칸이 항상 같은 정사각형 크기로 맞춰집니다. 이 `unit`은 화면 크기(뷰포트)에 맞춰 매번 다시 계산되며, 덱 안쪽에는 항상 여백이 남도록 계산해 카드가 위아래 가장자리에 붙어 잘린 것처럼 보이지 않게 합니다.
- **완성 연출**: 색종이 효과는 `<canvas>` 2D 컨텍스트로 직접 그리는 파티클 애니메이션이며, 팡파레 효과음은 Web Audio API(`AudioContext` + 오실레이터)로 그 자리에서 합성합니다. 둘 다 외부 이미지·음원 파일에 의존하지 않습니다.
- **PDF 생성**: `html2canvas`로 문제지 DOM을 고해상도(3배) 캔버스로 캡처한 뒤, `jsPDF`로 A4(210×297mm) 한 페이지에 그대로 삽입합니다.
- **한글 폰트**: Noto Sans KR을 이 앱에서 실제로 쓰는 글자만 골라 서브셋으로 만들어 `woff2`로 내장했습니다(폰트 파일 용량을 최소화). 외부 폰트 서비스에 연결하지 않습니다.
